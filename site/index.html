Built for the gym floor

  • 01

    Rest timer with flash alarm

    Starts when you log a set and flashes the screen when time is up, so a silenced phone cannot make you miss it.

  • 02

    Muscle heat map & recovery

    See which muscles are fresh and which are still recovering, drawn on a body map from your last sessions.

  • 03

    Offline-first sync

    Every set is saved on the device first and synced when there is signal. A basement gym loses nothing.

  • 04

    Ramp sets & weekly targets

    Planned warm-up sets log as their own rows, and optional weekly ladders raise each lift's starting weight week by week.

  • 05

    Supersets

    Pair exercises and ticking a set jumps you to the partner's next set, so the log follows how you actually train.

  • 06

    Haptics in a PWA

    Taps, completed sets and the finish all give physical feedback on iPhone, even without a native app.

  • 07

    AI-friendly JSON API

    Programs and sessions are plain JSON behind a documented API. Let a chatbot write your next block.

  • 08

    Own your data

    Self-host with Docker or Vercel. Your workouts are files you can read, back up and export.
